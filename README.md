# AI Orchestration Studio

## 1. 소개

서강대학교 AI 오케스트레이션 스튜디오(STS3001) 과목의 실습 과제를 정리한 저장소입니다. Python 기초부터 데이터 분석, 프롬프트 설계, LLM 응답 처리까지 주차별 학습 내용을 정리합니다.


## 2. 사용 기술

- **언어:** Python
- **라이브러리:** pandas, openpyxl, requests, python-dotenv (실습별 사용 라이브러리는 다를 수 있습니다.)


## 3. 주요 내용

주차별 과제 제출물을 폴더별로 관리합니다. 주요 실습 및 과제 내용은 다음과 같습니다.
- Python 프로그래밍 및 객체지향 기초
- CSV·Excel 데이터 전처리와 집계
- 오류가 있는 코드 분석 및 디버깅
- Zero-shot, Few-shot, CoT 프롬프트 비교
- 고객 리뷰 분류 및 LLM 응답의 JSON 파싱·검증


## 4. 진행 상태

6주차 과제까지 정리되어 있습니다. 이후 진행된 팀 프로젝트는 이 저장소에 포함하지 않습니다.
